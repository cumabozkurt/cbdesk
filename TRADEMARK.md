# Trademark

The name CBDesk and the project logo, when one exists, are used to identify
this project. No trademark search has been completed. Risk R-012 in the master
plan is still open. Do not treat this note as legal clearance, a registration,
or a license to use the name for a commercial product.

Until a search is recorded in `docs/brand/`, contributors should not print
merchandise, register domains in the project's name, or ship a binary that
presents itself as an official release. No official binary exists yet.

Source code is available under AGPL-3.0-or-later. That license covers the
copyright in the code. It is not a trademark license.
