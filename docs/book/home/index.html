CBDesk

A remote desktop that asks before anyone sees your screen. The session indicator stays visible and cannot be switched off.

Ekranınızı biri görmeden önce soran bir uzak masaüstü. Oturum göstergesi görünür kalır ve kapatılamaz.

Features / Özellikler

Consent

The person at the host approves. No answer within 30 seconds closes the connection. A ticket only locates a computer.

Ev sahibi onaylar. 30 saniye içinde yanıt yoksa bağlantı kapanır. Bilet yalnız yer tarifidir.

Visible session

The indicator has no off switch. Quick Support cannot enable unattended access.

Göstergenin kapatma anahtarı yoktur. Hızlı Destek gözetimsiz erişim açamaz.

No CBDesk account

No project identity server. An optional relay is one you name. This project does not run a public relay. A live symmetric NAT was not measured.

Proje kimlik sunucusu yoktur. Aktarıcı, sizin adlandırdığınızdır. Bu proje genel bir aktarıcı çalıştırmaz. Canlı bir simetrik NAT ölçülmedi.

Not 30 frames per second

The live picture is color, software VP8. The 1080p timings are one machine and one synthetic picture. Hardware encoders fail closed.

Canlı görüntü renkli yazılım VP8'dir. 1080p süreleri tek makine ve tek sentetik görüntüdür. Donanım kodlayıcıları açılınca hata verir.

Download / İndirme

The buttons go to GitHub. This page does not store the bytes. Each file is an unsigned alpha from v0.1.0-alpha.1. SHA256SUMS is a digest list, not a signature. The note on the release reads unsigned: CBDESK_SIGN_KEY is unset. No phone install and no performance run of these binaries was recorded. macOS files are Apple Silicon only, not universal, and not notarized. The Linux CLI links ubuntu-24.04 system libraries. The Android package is a debug APK and was not installed.

FAQ / SSS

Why did SmartScreen or Gatekeeper complain?

The alpha is unsigned. There is no Authenticode certificate and no Apple notarization. The warning is expected. Do not turn those protections off because a stranger asked you to.

SmartScreen veya Gatekeeper neden uyarı verdi?

Alfa imzasızdır. Authenticode sertifikası ve Apple noter kaydı yoktur. Uyarı beklenen sonuçtur. Bir yabancı istedi diye bu korumaları kapatmayın.

Is this a finished remote desktop?

No. Version 0.0.0 is not a release. The tag is not the plan's alpha exit. No smoke matrix was run by a person. No 30 frame-per-second stream was measured. See what is absent.

Bu bitmiş bir uzak masaüstü mü?

Hayır. 0.0.0 bir yayın değildir. Etiket, planın alfa çıkışı değildir. Duman matrisini bir kişi çalıştırmadı. 30 kare/saniye ölçülmedi. Bkz. neyin bulunmadığı.
